# Code of Conduct

Zonebots is a hobby project. We want it to be a place where beginners and experienced developers
enjoy working together.

- Be friendly and patient. Assume good intentions.
- Criticise code and ideas, never people.
- No harassment, insults or discrimination of any kind.
- Accept that maintainers may decline a change, and that they explain why.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may
block people who keep breaking them. If something is wrong, open an issue or contact a maintainer directly.
