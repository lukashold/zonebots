Z – ORIGINALFILME IM LOKALEN SPIEL

Die Browser-Fassung kann nach einem Sieg oder einer Niederlage den
Originalfilm der jeweiligen Mission starten. Nach der Siegesauswertung in
Mission 20 folgt zusätzlich der Kampagnen-Epilog. Mehrspieler-Partien
wechseln wie im Original direkt zur Auswertung.

Das Zusatzpaket wird aus der vorhandenen GOG-Installation erzeugt. Die
Spieldateien müssen nicht in den Browser geladen werden. Benötigt werden
Python und FFmpeg. Unter Windows im Projektordner ausführen:

  python tools/extract-original-result-films.py --include-epilogue --out C:\Z-Originalfilme
  python independent-engine/serve.py --films C:\Z-Originalfilme --port 8768

Falls FFmpeg nicht im Suchpfad liegt, beim ersten Befehl zusätzlich
--ffmpeg mit dem vollständigen Pfad zur ausführbaren Datei angeben.
Mit --language lässt sich die Originaltonspur wählen. Deutsch ist die
Voreinstellung. Der Server öffnet die lokale Spielseite im Browser.

Der Film startet nach dem Fort-Abschluss. Mit Escape oder „Film
überspringen“ geht es zur Auswertung. Blockiert der Browser die
automatische Tonwiedergabe, lässt sich der Film per Klick starten.
Den Epilog startet „OK“ in der letzten Auswertung. Danach geht es ins
Hauptmenü; ein neues Spiel beginnt wieder mit Mission 1. Ein vorhandenes
Filmpaket lässt sich mit --clip e_outro --append ergänzen.

Der lokale Filmserver bindet an 127.0.0.1. Das Zusatzpaket und die
Originalfilme gehören nicht zum öffentlichen Git-Repository.

ORIGINALTEXTUREN FÜR DIE AUSWERTUNG

Im Projektordner lässt sich das kleine Zusatzpaket aus der lokalen
Installation erzeugen. Python mit Pillow wird für die PNG-Prüfung gebraucht:

  python tools/extract-original-result-view.py --game "C:\GOG Games\Z" --output C:\Z-Ergebnisgrafik
  python independent-engine/serve.py --result-art C:\Z-Ergebnisgrafik --port 8768

Beide Optionen können kombiniert werden: --films C:\Z-Originalfilme
--result-art C:\Z-Ergebnisgrafik. Der Server setzt die erforderlichen
URL-Optionen und bindet an 127.0.0.1. Das Zusatzpaket enthält keine
GOG-Programmdateien und wird nicht vom LAN-Server ausgeliefert.
