ISOLATED SOURCE CANDIDATE: SPATIAL EXPLOSION AUDIO
================================================
This is a bounded successor to ORIGINAL-HARDWARE-AUDIO.txt and the historical
Owner4 paragraph in ORIGINAL-MP-AUDIO.txt. It is not deployment provenance.

ONE OWNER PER EXISTING LISTENER
The two former Game fields native_blast_sound_gate/native_blast_sound_cycle
and the World SetCrateSoundGate action are removed together. The sole runtime
4d18ee/4a6f4e owner is now original_audio::State.opportunity_gate:u8 and
explosion_cycle:u8, inside the already existing listener AudioState. Descriptor
stamps, effect_counter, master and listener view/generation retain their prior
owners. No extra camera state, clock, emitter, world pass or sound channel is
introduced. The historical nativeHardwareAudioContext event field is reused
for these newly converted spatial effects; audio.js is unchanged.

At the existing Main reset point both listeners' gate bytes are cleared. UI-only
callbacks, settings changes, camera changes and mission initialization do not
reset them. The cycle remains warm with the existing AudioState transfer. Cold
values are zero. A cycle outside0..7 produces InvalidCycle, not a masked guess.
The listener last accepted remote camera is a browser transport contract, not
an original network or device timing claim. Before a ready listener supplies
its view, MissingListenerView is recorded and no host camera is substituted.

REENTRY AND THE FIRST SUPPRESSED420200 PREFIX
After the existing synchronous world calls, falling/crate/fragment suffix probes
reload the current Raw44 record's origin, current projection and, where read,
current sprite. Inactive or reused records are not filtered. No earlier action
Vec position or Web-ID fallback substitutes for the source pointer. A missing
record yields MissingEffectRecord and leaves that unavailable suffix explicit.

The first420200 audio prefix reached by expiry1/7 is now called even while its
caller has4a6f42=1. The new128 native executions establish this audio prefix
before the existing environment-only world leaf. This addition does NOT prove
or implement that leaf's full420200 microFX/terrain/tail parity.4a6f42/4a6f4f,
quiet, strength, owner, terrain and the canonical World view remain one shared
World authority. Nothing reruns them for a listener. The actual Owner4/bridge
reentry Game test is distinct from the deliberately seeded current-record
suffix test; the latter does not claim a new native slot-reuse writer.

CHECKS
Private original oracles remain external inputs. The two new adapter checks
compare1536+128 executed source prefixes field by field. Their projected-state
FNV signatures are3102958722 and1031114429; they are not full raw-memory hashes.
The1536 proof includes a recorded fort-prefix policy case but does not wire an
unported fort destructor. Existing recorded-leaf FX wrappers are cfg(test) only;
they observe the source's intercepted audio requests without a second mixer.

The targeted Game checks cover asymmetric Owner4/bridge/crate order, source
RNG/terrain/HP/full500-record pool equality, missing/current-inactive stage
owners, warm cycle, Main-only reset and unavailable view. The actual App/Host/
Guest/private-Wasm test checks16 camera/master combinations, stale pending
decode after a real pan, and two actual wall-impact callbacks: HostEXP1 then
HostEXP2, while the guest moves near and receives its firstEXP1. It also checks
unchanged world output and that the guest never simulates. Existing24 hardware,
14 audio-session and20 listener endpoints remain checked.

These programs read the private original WAV bytes and exercise actual Audio.js
selection, loading, gain and BufferSource.start through instrumented WebAudio.
decodeAudioData returns a placeholder URL/duration; no PCM decoder, physical
device/mixer, speaker, SDK or GPU/raster equivalence is asserted. Source/private
Wasm and raw source oracle data are not part of the public code delta.
